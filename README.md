# Local Site Prototype

This is the responsive multi-page prototype for Yiwu Global Trade Co., Ltd.

Routes:

- `index.html`
- `products.html`
- `product.html?id=bosstech-bt-7628`
- `manufacturing.html`
- `about.html`
- `contact.html`

The catalog contains 142 products across nine categories. Prices are not exposed. Product and contact actions carry model context into WhatsApp at `+86 199 4762 6109`.

The `YG` monogram is a temporary text mark and should be replaced after the final Logo is supplied.
